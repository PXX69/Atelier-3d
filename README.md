# Atelier 3D

Modélisation 3D facile par assemblage de formes : cubes, sphères, cylindres, trous, groupes, export STL.

Ouvrir l'application : https://pxx69.github.io/Atelier-3d/

Sur Windows (Edge ou Chrome) et Android (Chrome), le menu du navigateur propose « Installer Atelier 3D ».
